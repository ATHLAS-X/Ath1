System Overview
End-to-End Pathway Platform

One lifecycle across all nine workflows: an association signs on, historical data is ingested and identities resolved, a trial cycle produces pre-camp dossiers, a committee selects a squad, and the selected squad is tracked weekly — feeding richer dossiers into the next cycle. This is the compounding loop the whole business rests on.

Grounded directly in §6 "Workflows" and the W9 master-flow diagram of the Pivot Document (v1.0, July 2026).

The compounding loop: Z5 → Z6 → Z7 → Z8 → Z10 → Z5. Each cycle makes the next cycle's dossiers better, which makes the association more dependent, which makes the data richer. Everything else in the platform is scaffolding around that loop — and that loop does not exist until Phase 0 proves the ingest cost on one real association.
